# Werkpages is deliberately not in search yet. See client/components/PageMeta.tsx.
#
# Crawling is ALLOWED on purpose. The pages answer with "noindex", and a crawler has to be able
# to fetch a page to read that. "Disallow: /" would block the fetch, so Google would never see
# the noindex - and a URL it heard about from a link elsewhere could still be listed bare, with
# no description and no straightforward way to get it removed.
#
# No Sitemap line while the site is hidden: there is no reason to hand over the URL set. The
# backend still serves /sitemap.xml, so restore the line here when Werkpages goes live.
